# @mcpm/feature-launcher

Opcjonalny feature MCPM przygotowujący bezpośrednie uruchamianie Minecrafta.

Aktualny etap udostępnia:

```text
mcpm launcher status
```

Komenda sprawdza aktywny projekt, wersję Minecrafta, loader, katalog gry, mody,
dostępność Javy i stan katalogu przyszłego runtime’u.

Kolejne etapy obejmą pobieranie runtime’u, uwierzytelnianie konta Microsoft i
właściwe polecenie `mcpm launch`.
